# Tanak Solanki — Software Engineering Portfolio

GitHub Pages-ready portfolio website, preserving all nine original slides and their original visuals from `Tanak-Solanki-Software-Engineering-Portfolio.pdf`. The responsive web wrapper adds accessible navigation and clickable GitHub project links without rewriting slide content.

## Deploy to your existing GitHub Pages repository

1. Keep a backup of the current `index.html` in `tanak-pixel/tanak-pixel.github.io`.
2. Copy this folder's `index.html` and `assets/` directory into the root of that repository (branch `main`). Keep the existing resume PDF.
3. Commit and push. If GitHub Pages is enabled for `main`/root, visit https://tanak-pixel.github.io/ to verify.

No build tools or dependencies are required. To view locally, open `index.html` in a browser.

**Note:** Slides are original-page raster images for pixel-accurate fidelity rather than editable HTML text. This preserves the content and visuals exactly, but text inside the slides cannot be selected or automatically reflow on narrow screens. Clickable links appear below each project slide.
